Soccer Data Analysis with YOLO

Project Overview
This project implements a soccer data analysis model using YOLO for object detection. It can identify players, the ball, and other relevant objects on the field to generate insights for performance analysis and strategy.

Acknowledgments

This project was inspired by a YouTube tutorial from Code in a Jiffy (https://www.youtube.com/watch?v=neBZ6huolkg). While I extended and adapted the project for my own purposes, I acknowledge that the core methodology and structure follow that tutorial. As such, I only claim partial credit for this work.

Features

Player and ball detection using YOLO

Custom dataset training and evaluation
